# McGill Care Compass v0.1.0

Release date: 2026-07-31

Production URL: <https://mcgill-care-compass.onrender.com>

## Release scope

This is the presentation-ready newcomer service navigator release. It includes:

- a single-container FastAPI and React application;
- structured intake across the locked service taxonomy;
- governed Silver RAG retrieval with source-linked recommendations;
- validated OpenAI-backed response generation with deterministic fallback;
- emergency-first, unsupported-input, sensitive-identifier, and system-error
  guardrails;
- strict liveness/readiness checks and signed SQLite/Chroma runtime artifacts;
- a freshness and maintenance transparency view;
- privacy-safe operational logging and developer diagnostics; and
- reproducible setup, data update, maintenance, rollback, and demo workflows.

Feature development was frozen on 2026-07-27. Only release-blocking fixes are
eligible for this release; other improvements remain future work.

## Maintenance disposition

The 2026-07-31 maintenance report contains 2,954 warnings and 0 errors. The
warnings cover freshness, failed-source review, and chunk-quality signals. They
remain visible to maintainers through the report generator, the read-only
maintenance endpoint, and the separate status/transparency view.

Maintenance warning text is not an input to recommendation generation and is
not inserted into user results. Recommendations use governed chunks plus
approved provenance and quality fields. Blocking integrity failures still fail
the maintenance error gate and readiness; warnings retain their recorded review
and refresh workflow.

## Known limitations

- The corpus is governed Silver data, not a manually approved Gold corpus.
- The corpus is English-only and excludes PDFs, login-gated pages, and
  JavaScript-only pages.
- Automated evaluation is not participant usability testing.
- Fixed evaluation retains one known top-three relevance miss:
  `R13_FREE_TAX_CLINIC`. Overall relevance remains 13/14 (92.9%), above the
  required 90% threshold, with all guardrail, limitation, source-link, and
  citation-grounding checks passing.
- The free hosted instance sleeps after inactivity, so the first request may
  take 50 seconds or more.
- OpenAI-backed wording depends on the configured provider key and service
  availability. The application falls back to deterministic, source-grounded
  wording when provider access fails or output validation fails.

## Rollback

Redeploy the previous known-good Render deployment or commit, wait for strict
readiness, and repeat routine, emergency, maintenance, privacy, and official
source checks. Do not serve a deployment whose readiness or safety checks fail.
